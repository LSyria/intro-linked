# Intro Linked

A video-first professional profile concept. A short intro plays in the circular profile-picture slot and pauses on its last frame as the profile photo.

This is an independent demonstration, not affiliated with LinkedIn.

## Preview

Once the frontend files are committed, open `index.html` or serve with `python3 -m http.server 8000`.

## Project status

Frontend prototype. Video uploads are previewed in the browser and are not stored on a server. Autoplay is muted according to browser restrictions.

## Deploy

GitHub Pages can be enabled under Settings > Pages with GitHub Actions as its build source. The repository contains a Pages deployment workflow.

## Note

The included demo portrait is user-supplied, and the placeholder audio/video is synthetic. Do not reuse the photo as stock media.
