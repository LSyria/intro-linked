# Intro Linked roadmap

## 1. Proof of concept — completed
- [x] Responsive professional profile
- [x] Embedded profile-picture video slot
- [x] Mute/autoplay, replay, last-frame freeze
- [x] Local preview/record for videos up to 30 seconds
- [x] Independent original website branding
- [x] GitHub repository and GitHub Pages deployment workflow

## 2. Real profile creation
- [ ] User sign-up, login and account recovery
- [ ] Authorized profile editing and optional link to LinkedIn
- [ ] Recorded-video uploads, trim tool, chosen photo frame
- [ ] Secure hosted storage, compression and captions
- [ ] Shareable profile links with public/private settings

## 3. Professional beta
- [ ] Accessibility and browser QA
- [ ] Media permissions, privacy disclosures, account deletion
- [ ] Abuse reporting, impersonation safeguards and moderation
- [ ] Consent-based recruiter analytics and performance metrics
- [ ] Pilot testing of 20–30-second introductions

## Not in scope
- Copying LinkedIn's brand, scraping accounts or accessing private profile data
- AI voice cloning or misleading synthetic testimonials

## Product hypothesis
A professional intro video replacing a static headshot increases meaningful engagement without distracting visitors. Test completion rate, voluntary replay, profile dwell time, contact intent and accessibility against a standard static-photo profile.
